## 🗺️ 4-Phase Roadmap

詳細は [docs/roadmap.md](docs/roadmap.md) を参照。

- [ ] **Phase 1: 基礎再構築 (0 〜 1,000h / 〜約10ヶ月)** ◀ *CURRENT*
  - 単語・文法・発音の徹底習得。オンライン英会話の開始、リスニングの習慣化。
- [ ] **Phase 2: 実践・習慣化 (1,000 〜 2,500h / 〜約1年3ヶ月)**
  - 英語ニュース、洋書読書、検定試験（TOEIC/英検1級）への挑戦。
- [ ] **Phase 3: 英語脳の定着 (2,500 〜 4,000h / 〜約1年3ヶ月)**
  - 情報収集・趣味（ドラマ/ゲーム/SNS）の完全英語化。英語での業務・発信。
- [ ] **Phase 4: 洗練・自動化 (4,000 〜 5,000h / 〜約10ヶ月)**
  - 高度なディスカッション、ネイティブ特有のニュアンス理解、思考の完全英語化。

## 🔄 Daily Workflow

1. **記録**: `logs/YYYY-MM.md` にその日の学習時間をカテゴリ別に記録。
2. **定着**: 新出単語は `notes/vocabulary.md`、読書/視聴メモは `notes/reading-notes.md`、ライティング練習は `notes/journal/` に追記。
3. **同期 (Daily Commit & Push)**: 
   ```bash
   git add .
   git commit -m "log: YYYY-MM-DD (+X.Xh, Total: Y.Yh)"
   git push origin main
   ```
