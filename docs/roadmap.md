# 5,000 Hours Roadmap & Strategy

## 1. プロジェクト目標とマイルストーン

- **総目標時間**: 5,000 時間
- **対象期間**: 2026年9月21日 〜 2030年11月18日（約 1,519 日）
- **起点レベル（Starting Baseline / 2026-09-21）**:
  - **TOEIC**: **420 点**
  - **CEFR スピーキング総合**: **B1 low** (CEST受検: 2025-05-26)
    - 語彙力: `B1 high` (表現語彙 1,200 / 理解語彙 2,500)
    - 文法: `B1 mid` (課題: 完了形・受動態・間接話法)
    - 発音・音韻: `A2 high` (課題: 音声変化、リズム・強弱、イントネーション)
    - 流暢さ: `A2 low` (課題: 間や詰まり、言い直しの低減)
    - 論理構成: `A2 low` (課題: 単純接続詞から複文・論理接続への昇華)
- **ゴールレベル（Target Mastery）**: **CEFR C1〜C2 / TOEIC 900+**
  - 複雑なビジネス・学術・専門領域のテーマについてネイティブと対等に議論・交渉できる。
  - 英語を「日本語に翻訳せず」、英語のまま思考し、瞬発力高くアウトプットできる。

## 2. ペース配分設計

### 2.1 基準スケジュール（約 1,519日）
- **1日あたり**: 約 **3.3 時間（3時間18分）**
- **1週間あたり**: 約 **23 時間**
- **1ヶ月あたり**: 約 **100 時間**

### 2.2 短縮挑戦プラン（1日5時間ペースの場合）
- **達成予定**: 2029年6月中旬（約 1,000日）
- **戦略**: 机に向かう学習（机上学習 1.5h）＋ 耳・目・日常の情報収集・エンタメの英語化（3.5h）を組み合わせる。

## 3. 4段階フェーズ詳細

### Phase 1: 基礎再構築 (0 〜 1,000 hrs / 目安: 〜約10ヶ月)
* **テーマ**: 土台の固め直しと学習習慣の定着
* **主な取り組み**:
  - **語彙・文法**: 基本〜中上級単語（3,000〜8,000語レベル）の総復習、コロケーション習得。
  - **発音・フォニックス**: 音声変化（Linking, Flapping, Reduction）のルール理解とシャドーイング。
  - **リスニング**: 英語Podcast（BBC 6 Minute English, All Ears English 等）を毎日の移動・家事ルーティンに。
  - **スピーキング**: オンライン英会話の習慣化（週3〜5回 / 1回25分）。

### Phase 2: 実践・習慣化 (1,000 〜 2,500 hrs / 目安: 〜約1年3ヶ月)
* **テーマ**: 読解スピードの向上とアウトプット量の拡大
* **主な取り組み**:
  - **リーディング**: 英語ニュース（The Economist, WSJ, Hacker News）や洋書（ノンフィクション・ペーパーバック）の多読。
  - **検定・指標**: 実力測定としてのTOEIC 900+ / 英検1級 / IELTS・TOEFL受験。
  - **ライティング**: 英語日記、学習内容の英語要約。

### Phase 3: 英語脳の定着 (2,500 〜 4,000 hrs / 目安: 〜約1年3ヶ月)
* **テーマ**: 生活・業務の英語比率最大化
* **主な取り組み**:
  - **環境の英語化**: スマホ・PC設定、YouTube、Netflix、ゲーム、技術調査の完全英語化。
  - **専門領域の深掘り**: 自身の専門・興味領域に関する論文、ドキュメント、業界ディスカッションへの参加。
  - **発信**: 英語でのSNS投稿、ブログ執筆、海外コミュニティでの発言。

### Phase 4: 洗練・自動化 (4,000 〜 5,000 hrs / 目安: 〜約10ヶ月)
* **テーマ**: ネイティブレベルの自然さと瞬発力
* **主な取り組み**:
  - **ディベート・交渉**: 論理構成、文化的背景を踏まえた高度なニュアンスの使い分け。
  - **イディオム・ユーモア**: 比喩、ウィット、スラング、ニュアンスの解像度向上。
  - **思考の完全自動化**: 思考言語としての英語の定着。
